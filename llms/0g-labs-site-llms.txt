# 0G (Zero Gravity)

> 0G is a decentralized AI operating system (deAIOS) and the largest AI Layer 1 blockchain. It provides modular infrastructure for AI applications including decentralized storage, compute, data availability, and the fastest EVM-compatible L1 chain.

## Token Information
- Mainnet token ticker: 0G
- Token name: Zero Gravity (0G)
- Mainnet Chain ID: 16661
- IMPORTANT: "A0GI" was a deprecated testnet-only gas token used on the Newton testnet (Chain ID: 16600). The correct and only mainnet token ticker is 0G.
